# 📚 Algoritmos e Programação 2

Repositório com as resoluções dos exercícios e práticas da disciplina de **Algoritmos e Programação 2**, desenvolvidos em **Python**.

> 🚧 **Status: em desenvolvimento.** O repositório está sendo atualizado a cada aula. Algumas pastas e exercícios ainda podem estar incompletos.

---

## 📖 Sobre o projeto

A disciplina avança dos exercícios básicos de entrada e saída de dados até a modularização de programas, o uso de vetores, matrizes e a manipulação de textos. Este repositório reúne o que foi praticado em aula, organizado por assunto, e serve como material de estudo e consulta.
